# v0.5.1 パッチノート

## ランチャー

- 現行の機能設定、共有地点、マルチプレイ用プロファイル、設計図配置、Levitation、テレポート機能を維持した安定ビルドを作成しました。
- Windows用NSISインストーラーを更新しました。

## ゲーム側の試験機能

以下は開発中のゲーム側試験パッチです。v0.5.1 のインストーラーによる自動導入対象ではありません。

- 100・1,000・10,000 corn 紙幣を追加
- 紙幣額面を合算する `/balance` を追加
- 手持ちの紙幣だけで正確に支払える場合に限り成立する `/pay` を追加
- 無限インベントリ中は経済コマンドを使えないように調整
- 紙幣モデルの接地位置を統一
- 紙幣のインベントリアイコンを額面表示付きへ更新

## 既知の制約

- SL4SM Bank、口座、預入・引出、取引履歴は v0.5.1 に含まれません。
- 通貨試験パッチを有効にしたマルチプレイでは、参加者全員のゲーム側パッチを一致させる必要があります。
