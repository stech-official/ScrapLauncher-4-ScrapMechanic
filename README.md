# v0.6.0 パッチノート

## 経済機能

- 通貨、スマホ、BANK、PAY を「経済機能」としてひとつのトグルへ統合しました。
- 初回の有効化時に、100・1,000・10,000 corn札の形状、モデル、アイコン、名称、スマホGUIをゲームフォルダーへ導入します。
- `/phone`、`/bank`、`/balance`、`/pay`、ホスト用の `/corn`・`/givecorn` をまとめて導入します。
- 無限インベントリ中は、従来どおり経済操作を実行できません。
- 無効化時は経済コマンドとゲーム側の実行処理を外し、アイコンマップは切替前の状態へ戻します。既存ワールドや所持している札を壊さないため、通貨アセット自体は残します。

## マルチプレイ

- ホスト設定プロファイルを v4 へ更新し、経済機能の有効・無効も参加者へ同期できるようにしました。

## 読み込みについて

- 経済機能を切り替えた次回起動では、通貨モデル・物理データ・アイコンを再読み込みします。最初の起動だけ通常より時間がかかる場合があります。
