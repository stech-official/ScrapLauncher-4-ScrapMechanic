# Scrap Launcher for ScrapMechanic  v0.6.3

## 新機能：紙幣リーダー

今回のリリースでは、ロジック作品に配置可能な、経済システム対応の紙幣リーダーが追加されました。

- ホストとして `/bankreader` を入力して入手してください。
- 標準のセンサーモデルを再利用しており、通常のロジックパーツに接続可能です。
- **E** キーを押すと、検知距離を 1 ～ 10 ブロックに設定できます。
- 検知条件として**100**、**1,000**、**10,000**、または**任意の**コーン紙幣を選択できます。
- リーダーは、一致する物理的な紙幣が前方にある狭い検知レーン内にある間のみ、信号を出力します。

## 修正内容

- 検知範囲がリーダー周辺を覆うのではなく、センサーの表面から始まるように修正しました。
- 設定された範囲は、メートルではなくビルディングブロック（1ブロックあたり0.25ワールド単位）で表されるようになりました。

## 更新ノート

インストール後、ランチャーで「経済」機能を一度保存し、Scrap Mechanicを再起動して、新しいアイテム、UI、およびスクリプトによる動作が読み込まれるようにしてください。
