# Scrap Launcher for ScrapMechanic v0.6.2

## 修正

- 経済機能の通貨用形状セットを、Scrap Mechanic が正式に読み込む `shapesets.json` へ登録するよう修正しました。
- これにより、100 / 1,000 / 10,000 corn 札の3Dモデルとインベントリアイコンが正しく表示されます。
- 経済機能を再適用しても登録が重複せず、OFF時には形状セット一覧を元に戻します。

## 導入後

1. v0.6.2 をインストールします。
2. ランチャーで「経済機能」をONのまま保存・適用します。
3. Scrap Mechanic を完全に終了してから起動します。初回はモデル・アイコンの再読み込みで時間がかかる場合があります。

既存のセーブデータ、BANK口座残高、所持中のcorn札は変更しません。
