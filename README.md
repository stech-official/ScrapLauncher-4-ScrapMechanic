# Scrap Launcher for ScrapMechanic v0.6.1

## 修正

- 経済機能のスマホ起動処理を修正しました。
  - `/phone` と `/bank` の起動演出が「起動中です…」のまま停止する問題を解消。
  - 経過時間・画面遷移・通信待機表示を更新する処理を、ゲームの毎フレーム更新へ確実に登録します。
- 経済機能をON/OFFまたは再適用しても、更新処理が重複・残留しないようにしました。

既存の口座残高、所持しているcorn札、ワールドおよびセーブデータは変更しません。v0.6.0を利用中の場合は、v0.6.1をインストール後に「経済機能」をONのまま保存・適用してください。
